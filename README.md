# Interactive Hover & Click Game

A simple and fun interactive web game built with HTML, CSS, and JavaScript.

## Features

### Square 1
- Shows a random number whenever the user hovers over it.

### Square 2
- Changes its color after every two hover events.

### Square 3
- Changes both its color and shape on hover.

### Square 4
- Changes the colors of Squares 1, 2, and 3 randomly when hovered.
- Displays an image when double-clicked.

## Technologies Used
- HTML
- CSS
- JavaScript
